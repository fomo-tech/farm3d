# Icon toast ImageGen

Dùng built-in ImageGen để tạo ba ảnh riêng có nền alpha, chuyển WebP 128×128 bảo toàn transparency bằng cwebp. Toast dùng ảnh mới thay icon quest/seeds/hand cũ. Bỏ chuông, badge và bảng lịch sử thông báo khỏi HUD theo yêu cầu. Thông báo toast vẫn hoạt động.

## Prompt set (final)

Shared prompt: Create ONE standalone [kind] toast status icon for a cozy 3D farming social mobile game, Play Together inspired toy aesthetic. Subject: [subject]. Sculpted actual 3D toy object, thick rounded bevels, matte plastic and softly painted wood, clear silhouette readable at 36px, warm cream sage coral turquoise palette, soft upper-left studio light, subtle ambient occlusion, almost front view with slight three-quarter depth. Centered square composition, generous transparent margin, entire object visible. Actual transparent alpha background. No scenery, no extra objects, no text captions, no watermark, no thin line art, no flat website vector look, no sparkles, no glossy metallic gradients. Match a premium casual farming game HUD.

- success subject: a chunky rounded sage green checkmark mounted on a small warm cream wooden farm sign badge
- warning subject: a chunky coral amber exclamation mark mounted on a small warm cream wooden farm sign badge
- info subject: a chunky turquoise lowercase information i mounted on a small warm cream wooden farm sign badge

Final files: public/assets/hud/toast-v1/success.webp, warning.webp, info.webp.

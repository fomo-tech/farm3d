# Farm icon direction sample

The ornate imagegen-v1 set was rejected for looking like website icons. Runtime no longer loads that set. A new backpack sample is generated with the built-in image_gen tool and exported as transparent WebP at 256×256, quality 90. Other icons currently use the previous v3 set; this is a direction sample, not a completed replacement family.

Prompt: One production inventory icon for a cozy 3D farming social game with the simple playful visual language of Play Together. Small farmer's canvas rucksack, warm ochre body, broad sage green front flap, cream straps and plain wooden toggle. Rounded low-poly geometry, broad clean color regions, matte painted material, almost no surface texture, no stitching, metallic trim, glass or glossy highlights. Friendly exaggerated proportions, readable at 32px. Front three-quarter orthographic view, warm soft light, subtle shading on object only. Centered complete object with clear margins on a transparent background; no tile, pedestal, text, logo or extra objects.

Asset: `public/assets/hud/farm-v1/backpack.webp`. `desktop.png` shows the production HUD preview on a neutral background. HUD runtime checks pass.

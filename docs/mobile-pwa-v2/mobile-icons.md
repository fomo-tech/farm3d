# Mobile HUD icons

Generated with the built-in imagegen tool, one transparent image per function. Exported as 128×128 alpha WebP at quality 90. Final assets: public/assets/hud/mobile-v1/. Original outputs remain in the generator directory.

Prompt sets with subjects and source paths: icon-generation-main.json and icon-generation.json. Shared prompt: premium rounded chunky stylized 3D toy art; warm orange #F5A64A, teal #43BCC0, cream #FFF3D6; upper-left soft light, clean silhouette at 32 pixels; single centered object; transparent alpha; no text, badge, background or web clipart.

Mobile-only responsive picture sources preserve the desktop icons. HUD actions declare iconAsset explicitly; fishing uses a rod and bobber, land uses a fenced plot, ticket uses a ticket, sprint uses speed streaks, jump uses an upward arrow.
